# モンスターコンストラクション

Repository: [cadmium2525/monster_collection](https://github.com/cadmium2525/monster_collection)

GitHub Pages: `https://cadmium2525.github.io/monster_collection/`

Sim8.7完全展開版を正本にした、スマートフォン横画面向けの静的Webカードゲームです。トーナメント4試合、勝利後のカード奪取、40枚の永続更新、上位大会解禁、レジェンド決勝の現チャンピオン戦まで一連に遊べます。

2026-08-24の仕様差分として、距離・得意距離・移動をゲーム判定から完全に廃止しています。盤面は距離を持たない3枠で、モンスター内包の実戦4技は任意の合法対象へ使います。マスターの `legacyDistance` は原典追跡専用で、UI・AI・ダメージ計算には使いません。

## ローカル起動

必要環境はNode.js 20以上です。外部npm依存はありません。

```sh
npm test
npm run dev
```

表示された `http://127.0.0.1:4173/` を開きます。Firebase未設定時も、保存先をこのブラウザのLocalStorageとして全ゲームループを利用できます。

本番相当のPages成果物は次で確認できます。

```sh
npm run build
npm run preview
```

## 遊び方

1. ホームから保存デッキを1つ選び、大会へエントリーします。
2. 手札カードをタップして選択し、モンスターは空き枠へ、Training・修行・対象指定ブリーダーは盤上モンスターへスワイプします。対象を取らないブリーダーは盤面の任意位置へスワイプします。
3. 盤上モンスターをタップすると、現在/最大LIFE・残存率・現在の状態・実戦技を確認できます。実戦技をタップし、光った相手モンスター（盤面が空なら相手LIFE）をタップして攻撃します。LIFE50%以下で効果が増える技は、条件を満たす対象へ具体的な増加内容を表示します。
4. 勝利後、相手40枚から提示された5枚のうち0〜2枚を選び、同数の自分のカードと交換します。
5. 交換確定時点の40枚は即時保存されます。敗退しても確定済みカードは残ります。
6. 優勝すると次大会がプレイヤー全体に解禁され、ほかの保存デッキでも挑戦できます。レジェンド決勝勝利で王座更新を試みます。
7. 現チャンピオンは、王座を獲得した大会の決勝開始時点における40枚と育成状態を再現してレジェンド決勝へ登場します。

大会中は、対戦前・進行中の試合・カード奪取の選択状態を操作ごとに自動保存します。ブラウザーを閉じたりPWAをタスクキルした場合も、次回起動時にホームの「大会の続きから」から復帰できます。大会終了後は再開データを終了済みとして保存し、古いクラウド書き込みで終わった大会が復活しないようにしています。

保存デッキ一覧では、各デッキの鉛筆アイコンから名前を変更できます。詳細画面ではデッキ内のモンスターからリーダーを選び直し、40枚を種類順・TP順・名前順・登録順へ並び替えて確認できます。並び替えは画面上の表示だけで、カード資産IDや対戦開始時のシャッフルには影響しません。一覧上部の「カード図鑑」では、一度でもデッキへ入ったカードと、プレイヤーが一度でも成功させた特殊合体を確認できます。右隣の「未所属カード」では、ブースターから入手してまだデッキへ所属させていない実所有資産を確認できます。カードを後で放出しても図鑑の発見履歴は消えません。

ホームの「ブースター」では6モン類の5枚パックを開封できます。初回は無料で、その後は大会報酬や毎日300ダイヤのログインボーナスで得るダイヤ300個を使います。2026年8月29日以降の初ログイン時は夏休みボーナス3,000ダイヤも一度だけ受け取れます。各パックの「収録カード・提供割合」では、次回の保証を反映した全収録カードと1パック内出現率を確認できます。獲得カードはまず未所属資産へ入り、保存デッキの「デッキ編集」で40枚と交換します。外したカードはそのデッキ専用プールへ残り、別デッキへは流用されません。詳しい排出・保証・報酬は [GACHA_SPEC.md](./GACHA_SPEC.md) を参照してください。

特別イラストとFoilはモンスターカードだけが持つ、所有者が見せるための外観資産です。相手から外観そのものを奪うことはできず、特別外観のカードが奪取候補に選ばれた場合は、同じ性能の通常イラストとして提示・獲得されます。旧データに育成・ブリーダーカードのプレミアム外観が残っている場合は、性能と枚数を維持したまま通常表示へ自動移行します。

特別イラストのモンスターをメインに特殊合体すると、完成形も同じ形態専用の特別イラストになります。通常絵の色違いではなく、48形態すべてで姿勢・カメラ・動作構図を変えた専用絵です。特殊合体特別絵は常にFoil光沢で表示します。素材側だけが特別絵の場合は発動せず、外観の所有価値をメインカードへ一貫して結び付けます。

修行では攻撃/防御別の候補一覧を確認後、seed付き乱数で技を1つ習得します。Rankによる確率差は小さくしています。5個目以降を覚えた場合は、その場で現在の実戦4技のどれかと入れ替えるか、「習得のみ」を選ぶまで次の行動へ進みません。Training・修行の成長は同じ大会の次試合へ持ち越され、大会終了時に消えます。カード構成と大会資格だけが永続です。

対戦相手も同じ大会内成長を持ちます。CPU同士の裏試合では、勝者が実際の40枚に含むTraining・修行だけをseed付きで使用し、正式な上昇値と技習得を次ラウンドへ持ち越します。対戦前画面には「勝ち上がり育成」として、それまでの試合数・能力上昇合計・新技数を表示します。現チャンピオンだけは新たな仮想育成を加えず、戴冠時に保存された決勝開始時の成長状態をそのまま使用します。

CPU同士の勝敗は次ラウンドの相手と育成を決めるため内部でseed付き確定しますが、トーナメント表では自分の同ラウンドが終わるまで「対戦中」と表示し、終了後にまとめて公開します。

初めて遊ぶ場合は、ホームの「遊び方」から7ステップのチュートリアルを開始できます。召喚、攻撃、育成、合体、TP、カード奪取までを順に確認できます。

カード面はイラスト、名称、四隅の主要数値を優先します。盤上ではLIFE50%以下をLIFEアイコンの発光で示し、強化▲・弱体▼・特殊◆の分類だけを小さく表示します。具体的な効果名と残り期間、特性やTraining・修行・ブリーダーの効果はタップ後の詳細画面で確認します。Training・修行の大会内持越しは「遊び方」とチュートリアルで説明します。ホームのdebug seedやSim番号などの技術情報は通常プレイでは表示されません。

各試合の開始時に、双方の40枚は試合seedから分岐したプレイヤー別seedでシャッフルされ、その後に初期3枚を引きます。通常プレイは大会を開始するたびに新しいseedを発行します。URLの `?seed=任意文字列` を使った場合だけ、同じ大会回数・ラウンドの順序をデバッグ用に再現します。山札切れ時も墓地をシャッフルして山札へ戻します。

## PWAとしてインストール

- Android/デスクトップChrome系: ホームに表示される「アプリに追加」またはブラウザーのインストール操作を使用。
- iPhone/iPad: Safariの共有ボタンから「ホーム画面に追加」を選択。
- 一度オンラインで起動すると、ゲーム本体とマスターデータを端末へ保存し、Firebase未接続時もオフラインでLocalStorageのデッキを遊べます。

王座の取得・更新やクラウド同期には通信が必要です。オフライン中に王座更新をローカル成功として偽装することはありません。

## アカウント復旧

ホーム右上の「マイページ」から、任意の復旧IDとパスワードを登録できます。メールアドレスは不要です。復旧IDは半角英字で始まる4〜20文字の英数字・ハイフン・アンダースコアで、大文字は小文字として扱います。現在の匿名UIDへ資格情報を追加するため、登録時にデッキやダイヤを別アカウントへ移す処理はありません。機種変更・再インストール後は「既存アカウントで復旧」から同じIDとパスワードを入力してください。

メールアドレスを登録しない方式のため、パスワード再設定メールは利用できません。復旧IDまたはパスワードを忘れた場合は現在の仕様では復旧できないので、端末外の安全な場所にも控えてください。

Firebase ConsoleではAnonymousに加えてEmail/Passwordプロバイダーを有効にする必要があります。詳しい設定と運用上の注意は [FIREBASE_SETUP.md](./FIREBASE_SETUP.md) を参照してください。

## 検証コマンド

```sh
npm test
npm run sim -- --a silver --b gold --games 20 --seed sample --time-ms 22 --summary
npm run sim:decks -- --runs 5 --seed sample --summary
npm run sim:tournament -- --rank bronze --runs 3 --player-ai legend --seed sample --time-ms 55 --summary
```

詳細出力から `--summary` を外すと、カード・技・特性統計と各試合seedを含む完全JSONを取得できます。URLへ `?seed=任意文字列` を付けるとブラウザ側の大会seedも固定できます。`&debug=1` の試合決着補助は `localhost` / `127.0.0.1` だけで有効です。

## 管理者ツール

公開URLまたはローカルURLへ `?admin=1` を付けると、ホーム右上に「管理者ツール」が表示されます。

- 基本カード87枚、特殊合体48種、通常特別イラスト30種、特殊合体特別イラスト48種の計213件を一括表示
- 種類・入手経路・カード名・ID・分類・効果文で検索／絞り込み
- 6分類のパックを、通常抽選・限定モンスター保証・Foil保証・特別絵保証で再現
- 任意seedで封印破壊からカード反転、レアリティ演出まで繰り返し確認

管理者ツールは表示確認専用です。ダイヤ、カード資産、保存デッキ、パック開封回数、Firebaseデータを変更しません。`admin=1`は秘密の認証キーではなく、読取専用の開発UIを表示するフラグです。

## Firebaseと公開

- Firebase設定: [FIREBASE_SETUP.md](./FIREBASE_SETUP.md)
- GitHub Pages公開: [GITHUB_PAGES_DEPLOY.md](./GITHUB_PAGES_DEPLOY.md)
- ルール: [firestore.rules](./firestore.rules)

Firebase Web設定値はプロジェクト識別子であり管理者秘密ではありませんが、アクセス制御はAuthenticationとSecurity Rulesへ依存します。静的クライアントだけでは勝利の改ざん耐性を証明できないため、競合安全な王座更新とサーバー権威の不正防止は別問題として扱っています。

データベースはRealtime DatabaseではなくCloud Firestoreです。プレイヤーがLegendを解禁した後の保存40枚を所有者管理の公開スナップショットとして共有し、レジェンド1〜3回戦の候補へ混ぜます。決勝は現チャンピオンが戴冠した大会の決勝開始時40枚と成長状態を再現します。
